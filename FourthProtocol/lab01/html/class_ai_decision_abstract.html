AI decides where to place tokens.

Take the current board state and win function (for checking if a play is a win) and loop through every potential play, and check if there is a winner, or if a block is necessary or if the ai has to block, if it has to block it will check if a three in a row is present (block an enemy win) or if a 2 in a row is present block that (future win if not near edge of board) otherwise it checks its heurustic and plays the best move
